# Inventory App

A web-based electronics inventory application built with Express, EJS, and PostgreSQL. It provides a storefront for browsing products and an inventory dashboard for managing products, categories, and stock.

## Live Demo

🔗 [Click here to view the live app](https://inventory-app-vssf.onrender.com)

## Features

- Browse products by category and search by product name or brand
- Sort and filter category listings
- Create and edit products and categories
- Password confirmation for product and category edits and deletions
- Dashboard with inventory statistics, low-stock alerts, recent products, category summaries, and a stock distribution chart
- Custom 404 and 500 pages

## Setup

1. Install dependencies:

   ```bash
   npm install
   ```

2. Create the database:

   ```sql
   CREATE DATABASE inventory_db;
   ```

3. Connect to `inventory_db` and create the tables:

   ```sql
   CREATE TABLE categories (
     id INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
     name TEXT NOT NULL UNIQUE,
     description TEXT
   );

   CREATE TABLE items (
     id INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
     external_id INTEGER UNIQUE,
     name TEXT NOT NULL,
     description TEXT,
     brand TEXT,
     price NUMERIC(10, 2) NOT NULL,
     stock_quantity INTEGER NOT NULL,
     image_url TEXT,
     category_id INTEGER NOT NULL REFERENCES categories(id) ON DELETE RESTRICT
   );
   ```

4. Update the PostgreSQL connection settings in `db/pool.js` to match your local setup.

5. Create a `.env` file in the project root and set an admin password:

   ```env
   ADMIN_PASSWORD=your-admin-password
   ```

   This password is requested when editing or deleting products and categories.

6. Optionally import sample categories and products from DummyJSON:

   ```bash
   node db/seed.js
   ```

## Run

Start the application:

```bash
node app.js
```

## Main pages

- `/` — Storefront and categories
- `/items/search?q=term` — Product search
- `/dashboard` — Inventory dashboard

Product and category create, edit, and delete pages are accessible through the application.
